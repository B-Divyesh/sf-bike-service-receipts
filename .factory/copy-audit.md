## README and legal copy

The README uses **Bike service features** as its feature heading. License
destination wording is covered by `license-verification-destination`. The
privacy and terms pages use the same tested wording. Billing operation,
merchant, tax, receipt, refund, and revocation statements were removed because
purchases are not open.
